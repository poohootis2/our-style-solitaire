# Our Style Solitaire 홈페이지

Google Play 등록용으로 만든 정적 단일 페이지 홈페이지입니다. `index.html`은 게임 소개 페이지이고, `privacy.html`은 개인정보처리방침입니다. 두 페이지를 같은 HTTPS 웹 호스팅에 올린 뒤 홈페이지 URL에는 `index.html` 주소를, 개인정보처리방침 URL에는 `privacy.html` 주소를 사용하세요.

## 포함된 필수 항목

- 게임 소개와 주요 기능
- 게임 스크린샷
- 문의 이메일: `poohootis2@gmail.com`
- AdMob 고지가 포함된 개인정보처리방침
- Google Play 출시 전 상태 표시

Google Play에 앱이 공개된 뒤 `index.html`의 `store-status` 영역을 실제 Google Play 링크로 바꾸면 됩니다.
