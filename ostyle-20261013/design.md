# Our Style Solitaire 1.6.0 — 모바일 인터페이스 설계

## 제품 방향

**Our Style Solitaire**는 한 손으로 가볍게 즐길 수 있는 클론다이크 솔리테어다. 화면은 전통적인 녹색 펠트가 아닌, 짙은 남색 바탕 위에 보랏빛 광택과 산뜻한 코랄 포인트를 얹은 현대적인 게임 테이블로 구성한다. 플레이 중에는 카드와 현재 선택 상태만이 분명하게 보이도록 정보의 밀도를 낮추며, 조작은 탭과 탭-대상 선택 흐름으로 완성한다.

모든 화면은 **9:16 세로 화면**을 기준으로 설계한다. 핵심 제어는 화면 하단 또는 양쪽 엄지의 닿기 쉬운 영역에 두고, 카드 영역에는 충분한 터치 여백을 제공한다. 시스템 탭 바는 사용하지 않으며, 플레이 흐름을 방해하지 않는 인게임 오버레이만 사용한다.

## 화면 목록과 콘텐츠

| 화면 | 주요 콘텐츠 | 주요 기능 |
|---|---|---|
| 게임 테이블 | 스톡, 웨이스트, 4개 파운데이션, 7개 타블로, 점수·시간·이동 수 | 카드 탭 선택, 이동 대상 탭, 카드 뒤집기, 스톡 드로우, 자동 완성 |
| 일시정지 시트 | 게임 재개, 새 게임, 규칙 보기 | 플레이를 유지한 채 모달 형태로 제어 |
| 새 게임 확인 시트 | 새 게임 시작, 취소 | 현재 게임을 실수로 덮어쓰지 않도록 확인 |
| 기록 시트 | 현재 세션의 최고 점수, 최단 시간, 승리 수 | 로컬 저장 게임 기록 확인 및 초기화 |
| 규칙 시트 | 클론다이크의 배치·이동·승리 조건 | 초보자가 인게임에서 즉시 확인 |
| 승리 시트 | 최종 점수, 시간, 이동 수, 새 게임 | 자동 완성 후 결과를 확인하고 다음 판 시작 |

## 핵심 사용자 흐름

| 사용자 목표 | 흐름 |
|---|---|
| 게임 시작 | 앱 실행 → 셔플된 클론다이크 테이블 표시 → 즉시 플레이 |
| 카드 이동 | 카드 또는 카드 묶음 탭 → 가능한 대상 카드 또는 빈 열 탭 → 이동 성공 피드백 |
| 카드 공개 | 타블로의 뒷면 카드 탭 → 카드 앞면으로 전환 → 점수 반영 |
| 덱 순환 | 스톡 탭 → 웨이스트로 한 장 이동 → 스톡 소진 시 다시 탭하여 순환 |
| 기록 보기 | 상단 메뉴 탭 → 기록 탭 → 로컬 최고 기록 확인 |
| 승리 후 재시작 | 파운데이션을 모두 완성 → 승리 시트 → 새 게임 탭 |

## 조작과 피드백 원칙

카드는 한 번 탭해 선택하고, 이동할 카드 또는 빈 타블로 열을 다시 탭해 이동한다. 선택된 카드는 코랄 외곽선과 약한 상승으로 분명히 표시한다. 유효한 이동에는 짧은 촉각 피드백을, 카드 공개·완성에는 더 명확한 성공 피드백을 사용한다. 움직일 수 없는 카드를 탭한 경우에는 게임 흐름을 중단하지 않는 작은 흔들림 또는 미세한 밝기 변화로만 반응한다.

게임 상태와 기록은 기기 내부에 저장한다. 로그인이나 클라우드 동기화는 사용자 요구에 포함되지 않았으므로 추가하지 않는다.
