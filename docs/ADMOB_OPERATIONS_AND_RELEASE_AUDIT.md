# AdMob 운영 수칙 및 출시 전 설정 점검

## 점검 결론

현재 프로젝트는 **개발 빌드와 운영 빌드의 광고 단위 ID를 분리**하고 있습니다. 개발 빌드에서는 Google 테스트 광고 ID를 사용하며, 릴리스 빌드에서는 등록된 배너·보상형 광고 단위 ID를 사용합니다. Expo 설정에는 실제 AdMob 앱 ID와 Android 광고 ID 권한이 포함되어 있습니다.

| 점검 항목 | 결과 | 코드·설정 위치 |
|---|---|---|
| AdMob Android 앱 ID | 통과 | `app.config.ts`의 `react-native-google-mobile-ads` 플러그인 |
| Android 광고 ID 권한 | 통과 | `app.config.ts`의 `com.google.android.gms.permission.AD_ID` |
| 배너 광고 단위 | 통과 | 개발 `TestIds.BANNER`, 릴리스 실제 배너 단위 ID |
| 보상형 광고 단위 | 통과 | 개발 `TestIds.REWARDED`, 릴리스 실제 보상형 단위 ID |
| 보상 지급 시점 | 통과 | 보상 이벤트를 받은 후 광고가 닫힐 때 자석 1회 지급 |
| 중도 종료·로드 실패 | 통과 | 자석 미지급, 재시도 안내 표시 |
| 앱 버전 | 확인 필요 | `versionCode 24`, Google Play에 24가 이미 업로드되었다면 다음 빌드는 25 이상 필요 |

## 무효 트래픽 예방 수칙

Google은 광고주 비용 또는 게시자 수익을 인위적으로 높일 수 있는 클릭·노출을 무효 트래픽으로 봅니다. 개발자 자신의 실제 광고 클릭, 같은 사용자의 반복 클릭·노출, 광고 클릭을 유도하는 표현이나 배치, 자동 클릭 도구는 모두 피해야 합니다.[1]

| 운영 상황 | 해야 할 일 | 하지 말아야 할 일 |
|---|---|---|
| 개발 중 | 현재 프로젝트처럼 테스트 광고 단위를 사용합니다. | 실제 광고를 눌러 동작을 시험하지 않습니다. |
| 출시용 AAB 내부 테스트 | AdMob 콘솔에서 본인 기기를 테스트 기기로 등록한 뒤 테스트 광고로 확인합니다. | 본인 휴대폰에서 실제 광고를 반복 클릭하거나 가족·지인에게 클릭을 요청하지 않습니다. |
| 보상형 광고 UX | `광고 시청 후 자석 1회 획득`처럼 실제 보상만 명확하게 설명합니다. | 광고 클릭을 요구하거나 광고 콘텐츠와 무관한 클릭을 유도하지 않습니다. |
| 배너 광고 배치 | 게임 조작 버튼·카드·닫기 버튼과 충분한 거리를 둡니다. | 사용자가 실수로 누를 위치에 배너를 겹치게 하지 않습니다. |
| 트래픽 이상 징후 | AdMob의 노출·클릭·예상 수익 변화를 확인하고 의심스러운 급증은 기록합니다. | 비정상 클릭을 숨기거나 봇·자동화 트래픽을 사용하지 않습니다. |

> 개발 중에는 테스트 광고를 사용해야 하며, 테스트 모드가 아닌 실제 광고를 너무 많이 클릭하면 무효 활동으로 계정이 신고될 수 있습니다.[2]

## 출시 직전 실행 순서

1. Android Studio로 생성하는 출시 AAB가 현재 `app.config.ts` 기준인지 확인합니다. 오래된 `android/` 폴더를 사용한다면 `npx expo prebuild --platform android`로 설정을 반영한 뒤 서명 빌드합니다.
2. **본인 기기에서 출시 AAB를 확인해야 한다면**, AdMob 콘솔에서 그 기기를 테스트 기기로 등록합니다. 테스트 기기는 계정 보고서에 요청·노출·클릭이 집계되지 않습니다.[2]
3. 실제 광고 단위 ID를 유지한 릴리스 AAB에서는 광고를 직접 클릭하지 않습니다. 보상형 광고는 끝까지 시청하면 자석이 지급되고, 중도 종료 또는 로드 실패 시 지급되지 않는지 기능만 확인합니다.
4. `versionCode`가 Play Console에 이미 올린 모든 버전보다 큰지 확인한 뒤 업로드합니다.

## 현재 광고 동작

운영 릴리스에서 배너와 보상형 광고는 AdMob이 광고를 정상적으로 제공할 수 있을 때 표시됩니다. 보상형 광고는 보상 이벤트가 발생한 뒤 닫힐 때 자석 1회가 지급됩니다. 광고를 중간에 닫거나 광고 로드에 실패하면 자석은 지급되지 않습니다. 자석은 자동으로 사용되지 않으며, 사용자가 자석 버튼을 눌러 자동 정렬을 실행합니다.
