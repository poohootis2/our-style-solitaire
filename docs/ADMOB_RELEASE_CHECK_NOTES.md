# AdMob 출시 전 점검 메모

## 공식 정책 조사 결과

- 무효 트래픽에는 개발자 본인의 실제 광고 클릭·노출, 반복 클릭·노출, 클릭을 유도하는 문구 또는 배치, 자동 클릭 도구가 포함됩니다.
- 개발 중에는 Google 데모 광고 단위 또는 테스트 기기를 사용해야 하며, 테스트 모드가 아닌 실제 광고를 반복 클릭하면 무효 활동으로 신고될 수 있습니다.
- 앱 출시 전에는 데모 광고 단위와 테스트 기기 ID 설정을 제거하고 실제 광고 단위 ID를 사용해야 합니다.
